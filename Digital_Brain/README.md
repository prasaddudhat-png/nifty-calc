# 🧠 Welcome to Your Digital Brain

This directory structure is modeled after the Obsidian / Claude Code methodology for building a permanent, highly-digestible knowledge base for your AI workflows.

By keeping all your thoughts, logic, history, and rules in these folders, you solve "chat amnesia." Any AI model (Cursor, Claude, Gemini, ChatGPT) can scan this folder and immediately align with your exact business logic and past coding sessions.

## 📂 Vault Structure

*   **`00_Context/`**: High-level documents about your project, your coding style, your target audience, and your "system architecture." (We have moved your `AI_BRAIN.md` here).
*   **`01_SOPs/`**: Standard Operating Procedures. Step-by-step guides on how you do things (e.g., "How we deploy the backend", "How to add a new chart").
*   **`02_History/`**: Dump all your exported chat histories here. When the AI scans this, it understands the *evolution* of your project and the "why" behind your code.
*   **`03_Projects/`**: Active notes, technical specifications, and roadmaps for what you are currently building (e.g., "Mobile App Integration Plan").
*   **`04_Resources/`**: External documentation, API references (like Angel One API docs), or snippets you frequently use.

## 🔗 How to use it:
1. **Download Obsidian**: If you haven't already, download [Obsidian.md](https://obsidian.md/) and open this `Digital_Brain` folder as a Vault. You'll see a graph view of how everything connects!
2. **Link Everything**: Inside Obsidian, use `[[Double Brackets]]` to link concepts together. For example, link a Project file to an SOP file.
3. **Use with your AI Editor**: If you use Cursor or Claude Code, just reference this folder. The AI will read the markdown files and know exactly what to do.
